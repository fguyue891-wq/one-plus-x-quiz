# 1+X随机刷题网页

## 使用方式

### 电脑和手机在同一 Wi-Fi

1. 双击 `启动刷题网页.bat`。
2. 窗口中会显示类似 `http://192.168.1.10:8080` 的地址。
3. 手机浏览器打开该地址。
4. iPhone 必须使用 Safari 打开该地址。
5. 点击 Safari 底部的“分享”按钮，选择“添加到主屏幕”，再点“添加”。
6. 从主屏幕打开后，练习记录会保存在这台 iPhone 的 Safari 中。

### 数据说明

- 每次随机抽取 100 道题，抽取范围共 390 道。
- 答题进度、练习成绩和错题本保存在当前浏览器。
- 清理浏览器数据、更换浏览器或更换手机不会自动同步记录。
- 可在“练习记录”页面导出 JSON 备份，并在另一台设备导入。

## 题型

- 单选题：240 道
- 多选题：30 道
- 配伍题：44 组，拆分为 120 道独立小题

答案来自 `1+X题库.docx`。解析根据题干、正确选项和题型自动生成，用于回顾判断依据。

## 单文件版本

如果不方便启动本地服务器，可直接把 `1+X随机刷题-手机单文件版.html` 发送到手机并打开。该版本无需其他文件即可使用。

注意：部分手机浏览器会限制 `file://` 页面保存数据。若发现记录无法保留，仍建议使用上面的本地 HTTP 方式打开。


## 更新内容

- 新增按题型顺序刷题：单项选择题、多项选择题、配伍选择题三个模块。
- 随机刷题和顺序刷题共用刷题进度，任一模式做过的题都会计入对应模块。
- 首页显示全部题库进度，顺序刷题页显示每个模块进度。
- 每道题确认答案后立即显示对错、正确选项和解析，再点击“下一题”。

## 解析版本

- 390 道题均配置了逐题解析，不再使用统一占位模板。
- 单选和多选解析说明正确知识点，并指出主要干扰项为什么不合适。
- 配伍题解析说明同一组选项之间的区别和每个小题的匹配依据。
- 发现配伍题第 11 组原答案钥与第 10 组同一药理关系发生错位，已按药理学判断更正为：双膦酸钠抑制骨吸收、甲状旁腺激素促进骨形成、维生素 D 促进骨钙化。
